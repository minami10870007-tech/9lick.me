# 9lick.me

短縮URL・クリック計測サービス **9lick.me** のコーポレートサイト。

静的HTML 1ファイルで完結しています。ビルド工程はありません。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | サイト本体（HTML・CSS・JavaScript をすべて内包） |
| `hero.png` | トップページのキービジュアル（1671×941） |

## ページ構成

1画面のHTMLの中で5ページを切り替える構成です。ページ切り替えはJavaScriptが担当し、URLのハッシュ（`#/service` など）は共有用のディープリンクとして同期されます。

- `#/home` — ホーム（キービジュアル、動く短縮デモ、実績数値、特徴、3ステップ）
- `#/service` — サービス（機能一覧、計測ダッシュボードの例、API、信頼性）
- `#/pricing` — 料金（4プラン、FAQ）
- `#/company` — 会社概要（ミッション、価値観、会社情報）
- `#/contact` — お問い合わせ（フォーム、連絡先）

## ローカルでの確認

`index.html` をブラウザで直接開けば表示されます。

## 公開する場合

GitHub Pages で公開できます。リポジトリの Settings → Pages → Source で `main` ブランチのルート（`/`）を選ぶと、`https://minami10870007-tech.github.io/9lick.me/` で配信されます。独自ドメイン（9lick.me）を使う場合は、同じ画面の Custom domain に設定したうえで、DNS側にCNAMEレコードを追加してください。

## 公開前に差し替えが必要な箇所

いずれも仮の内容です。実態に合わせて `index.html` を編集してください。

**会社概要（`#/company`）の未記入項目** — 運営会社の正式名称、代表者、設立、所在地、資本金、従業員数。ページ上では `—` と点線の枠で表示されており、未記入であることが分かるようになっています。

**実績数値（ホーム）** — 累計リダイレクト数 4.2億、リダイレクト応答 p95 38ms、稼働率 99.99%、導入アカウント数 1,400社。

**料金（`#/pricing`）** — Starter ¥1,480／Pro ¥4,800 などの価格、各プランの上限値。

**連絡先（`#/contact`）** — `contact@9lick.me`、`support@9lick.me`、`status.9lick.me`。

**お問い合わせフォーム** — 現在は送信先が未接続で、送信するとメールアドレスを案内する表示になります。実際に送信できるようにするには、`index.html` 末尾のフォーム送信処理に送信先エンドポイントを追加してください。

## デザインの前提

- 配色はライト／ダークの両テーマをCSSカスタムプロパティで定義。ヘッダー右上のボタンで切り替わり、選択は `localStorage` に保存されます。
- フォントは Google Fonts から M PLUS Rounded 1c（日本語）、Bricolage Grotesque（英字見出し・数字）、Space Mono（URL・コード）を読み込んでいます。
- 外部ライブラリは使用していません。
